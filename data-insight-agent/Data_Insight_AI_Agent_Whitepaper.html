Data Insight AI Agent

An Autonomous, Multi-Format Data Intelligence Agent with Sandboxed Code Execution, Statistical Profiling & Interactive Visual Analytics
Model Core: Google Gemini 2.5 Flash / 1.5 Pro  |  Pattern: ReAct & Code Interpreter  |  Engine: Streamlit, Plotly, DuckDB, Pandas

1. Executive Overview & Product Vision

The Data Insight AI Agent is an intelligent system designed to eliminate the friction of exploratory data analysis (EDA). Traditional data analysis workflows require data engineers to write bespoke ingestion scripts for different file formats, formulate manual SQL/pandas aggregations, and hand-craft charts in BI tools like Tableau or PowerBI.

This system replaces manual EDA with a unified agentic loop: users provide arbitrary data files (CSV, multi-tab Excel, nested JSON, Parquet, or SQLite databases), and the agent autonomously handles ingestion, data hygiene audits, outlier discovery, interactive Plotly visualization, and conversational natural-language Q&A backed by deterministic Python code execution.

4. Core Mathematical Algorithms

A. Outlier Detection via Tukey's Fences (IQR Method)

Unlike Z-score metrics that incorrectly assume Gaussian normal distribution, the agent employs non-parametric Interquartile Range fences to detect outliers robustly:

IQR = Q3 - Q1
Lower Bound = Q1 - (1.5 × IQR)
Upper Bound = Q3 + (1.5 × IQR)
Anomaly Condition: value < Lower Bound OR value > Upper Bound

B. Pearson Product-Moment Correlation Matrix

Linear dependencies across all numeric feature combinations are determined via normalized covariance:

rxy = ∑[(xi - x̄)(yi - ȳ)] / [ √∑(xi - x̄)2 × √∑(yi - ȳ)2 ]

C. Lexical & AST Security Analysis

Before any synthesized code snippet is passed to the execution namespace, it is evaluated against a disallowed module regex:

DISALLOWED = ["os", "subprocess", "shutil", "sys", "socket", "urllib", "requests", "http", "pathlib", "__import__"] # Any matching token terminates execution before bytecode evaluation

6. Security, API Key Management & Governance

Enterprise Security Safeguards
  • Stateless API Key Handling: API keys entered in the sidebar reside strictly in ephemeral Streamlit session state and are never logged or stored to disk.
  • Memory Copy Isolation: The Code Interpreter executes transformations strictly on df.copy(), preventing accidental modification or corruption of the source dataset.
  • Restricted Builtins: Host-level file writing (open(..., 'w')) and system process spawns are strictly blocked by the AST interpreter guard.
